# Modules

Eight modules, one per theme of the map. Each one is 20-30 minutes of presentation and discussion and has the same shape:

1. **Why it matters**: the shift in one paragraph.
2. **Key ideas**: the points from the map, explained with examples from the demo app.
3. **Discuss**: questions for the room.
4. **Exercise**: 10-15 minutes, pen-and-paper or in the repo.
5. **Takeaways by role**: QA, developers, managers.
6. **Practise it**: the labs that go with the module.
