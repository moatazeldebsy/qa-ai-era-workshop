# Your notebook

Some lab steps are thinking work, not code: a partition table, an exploration charter, a decision. You write those here, one folder per topic, and commit them to your fork. Over the course this folder becomes a portfolio of how you think about quality.

```bash
mkdir -p notebook/01
cp notebook/_templates/01/charter.md notebook/01/charter.md
```

Every template has ✏️ placeholders. Replace each one with your own answer. `npm run learn:check <topic>` treats a notebook page as done when no ✏️ is left, so a step can't be ticked off with the blank template.

There are no "right" answers in the notebook. Compare yours with other learners in the topic's discussion thread.
